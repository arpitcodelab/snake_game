# Plan 01-01: Project Foundation & Core Canvas Loop

## Objective
Scaffold the modular vanilla ES6 project structure, copy and organize scraped Google Snake assets into `assets/`, establish the HTML5 canvas rendering loop, and implement the core `Snake` entity with responsive keyboard controls, input buffering, and collision detection.

---

## Tasks

### Task 1: Project Scaffolding & Asset Organization
**Type**: Scaffold & Assets  
**Requirements**: CORE-01  
**Action**:
1. Create directory tree:
   - `assets/images/fruits/`, `assets/images/ui/`, `assets/audio/`
   - `css/`
   - `js/core/`, `js/entities/`, `js/systems/`, `js/modes/`, `js/renderer/`, `js/ui/`, `js/audio/`, `js/utils/`
2. Copy scraped image assets from `snake/game/snake/images/` to `assets/images/`:
   - `apple_types.png` -> `assets/images/fruits/apple_types.png`
   - `trophy_types.png`, `die.png`, `eat.png`, `effect.png`, `blink.png`, `tongue.png`, `default_end.png`, `rainbow_end.png`, `end_empty.png`, `keys.svg`, UI icon PNGs -> `assets/images/`
3. Create `js/utils/Constants.js`:
   - Define `GRID = { SMALL: { cols: 20, rows: 20 }, MEDIUM: { cols: 30, rows: 30 }, LARGE: { cols: 40, rows: 40 } }`
   - Define `SPEED = { BASE_MS: 150, MIN_MS: 60, STEP_DOWN: 2 }`
   - Define `CANVAS_SIZE = 600`
   - Define direction vectors `DIR = { UP: {x: 0, y: -1}, DOWN: {x: 0, y: 1}, LEFT: {x: -1, y: 0}, RIGHT: {x: 1, y: 0} }`
4. Create `js/utils/Vector2.js`:
   - Vector operations helper (`add`, `equals`, `clone`).
5. Create `js/core/EventBus.js`:
   - Decoupled pub/sub event emitter (`on`, `off`, `emit`).

### Task 2: Core Canvas, Viewport Scaling & Game Loop
**Type**: Rendering & Loop  
**Requirements**: CORE-01, CTRL-04  
**Action**:
1. Create `index.html`:
   - Viewport meta tags, container layout, canvas element `#game-canvas` (600x600 logical).
   - Link `css/main.css` and load `js/main.js` as `type="module"`.
2. Create `css/main.css`:
   - Reset, centering layout, dark background `#161616`.
   - Canvas styling with `touch-action: none;` and crisp pixel-art rendering (`image-rendering: pixelated;`).
3. Create `js/core/GameLoop.js`:
   - `requestAnimationFrame` loop tracking delta time.
   - Separate update ticks (based on current snake speed interval) from render frames (60fps).
4. Create `js/renderer/GridRenderer.js`:
   - Clear canvas, fill background color, draw subtle grid lines according to active grid dimensions.
5. Create `js/renderer/Renderer.js`:
   - Master renderer coordinating `GridRenderer`, `SnakeRenderer`, and future renderers.
   - High-DPI (`devicePixelRatio`) scaling helper to keep canvas razor-sharp.

### Task 3: Snake Entity, Input Buffering & Collision Engine
**Type**: Gameplay Mechanics  
**Requirements**: CORE-02, CORE-03, CORE-04, CORE-05, CTRL-01  
**Action**:
1. Create `js/entities/Snake.js`:
   - Store `body`: array of `{x, y}` grid coordinates (head at index 0, initial length 3).
   - Track `direction` and `nextDirection`.
   - Methods: `move()`, `grow()`, `setDirection(dir)`, `reset()`.
2. Create `js/core/InputManager.js`:
   - Listen to `keydown` events for Arrow Keys (`ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`) and WASD (`KeyW`, `KeyS`, `KeyA`, `KeyD`).
   - Maintain a 2-direction input buffer queue.
   - Prevent 180-degree instant reversal (e.g. moving Right cannot immediately accept Left).
   - Prevent browser default scrolling when arrow keys are pressed.
3. Create `js/systems/CollisionSystem.js`:
   - `checkWallCollision(head, grid)`: returns true if head is out of grid bounds.
   - `checkSelfCollision(head, body)`: returns true if head coordinates match any body segment (index > 0).
4. Create `js/renderer/SnakeRenderer.js`:
   - Draw snake head (distinct color/shape) and rounded body segments on the canvas grid cells.
5. Create `js/core/Game.js` and `js/main.js`:
   - Initialize `GameLoop`, `InputManager`, `Snake`, `CollisionSystem`, and `Renderer`.
   - On tick: flush input buffer, update snake position, check collisions.
   - On collision: emit `game:over`, stop loop, log game over state.
   - On render: call `Renderer.draw(snake, grid)`.

## Verification Plan
1. **Directory & Asset Verification**:
   - Check that `assets/images/fruits/apple_types.png` and other assets exist.
2. **Visual & Loop Verification**:
   - Open `index.html` in browser (or via local static server).
   - Canvas displays centered with a clean dark theme and subtle grid lines.
   - Snake spawns at center and moves steadily rightward at 150ms per step.
3. **Controls & Input Buffering Verification**:
   - Press Arrow Keys and WASD to verify steering.
   - Rapidly press `Down` then `Left` while moving `Right` to verify buffered turn without reversing into itself.
4. **Collision Verification**:
   - Drive snake into wall: verify game loop halts and console outputs game over.
   - Restart and steer snake in a loop to collide with its body: verify self-collision halts game.
