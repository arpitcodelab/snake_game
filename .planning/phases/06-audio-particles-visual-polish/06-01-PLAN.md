# Plan 06-01: Audio, Particles & Visual Polish

## Goal
Implement procedural Web Audio sound synthesis, fruit particle bursts, floating score indicators, collision screen shake, and HUD audio mute controls.

## Requirements Addressed
- **FX-01**: Audio manager with sound effects (eat, die, move, speedup, highscore) with mute/unmute toggle.
- **FX-02**: Procedural Web Audio API sound synthesis as zero-dependency fallback.
- **FX-03**: Particle effects system on fruit consumption (burst of colored particles matching fruit color).
- **FX-04**: Screen shake and death animation on collision / game over.
- **FX-05**: Floating score popups (+1, +3, +10) that float upward and fade out when fruits are eaten.

## Delivered Files
- `js/audio/AudioManager.js`: Web Audio API procedural sound synthesis (eat, die, fanfare, click) with mute state and localStorage persistence.
- `js/effects/Particle.js`: Particle physics model with velocity, gravity, friction, alpha decay, and FloatingText score popups.
- `js/effects/ParticleSystem.js`: Particle manager coordinating fruit bursts and floating text.
- `js/renderer/Renderer.js`: Screen shake logic and particle system rendering pipeline.
- `js/core/Game.js`: Event wiring for sound effects, particle bursts, screen shake, and score fanfare.
- `index.html` & `css/hud.css`: HUD mute button (`#btn-mute-hud`) with icon state toggling.
- `js/main.js`: Mute button event listener and window exposure.

## Verification
- Syntax checked with `node --check`.
- Verified with unit tests covering particle physics, floating text, particle system spawning and lifecycle, audio manager mute state and persistence, and mock canvas draw.
