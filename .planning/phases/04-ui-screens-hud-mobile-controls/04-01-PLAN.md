# Plan 04-01: UI Screens, HUD & Mobile Controls

## Objective
Implement the complete UI screen flow (Start Screen, Game HUD, Pause overlay, Game Over modal, Settings panel) and mobile input system (touch swipe + on-screen D-pad), fully responsive across desktop and mobile screens.

---

## Tasks

### Task 1: ScreenManager, Start Screen & Game Over Modal
**Type**: UI & State Flow  
**Requirements**: UI-01, UI-02, UI-04  
**Action**:
1. Create `js/ui/ScreenManager.js`:
   - Controls visible screens: `start`, `game`, `gameover`, and `settings` overlay.
   - Listens to `game:over` to show Game Over modal with score & high score.
2. Create `js/ui/StartScreen.js`:
   - Play button (boots game), Settings button (opens settings modal), displays high score.
3. Create `js/ui/GameOverScreen.js`:
   - Shows final score, high score, "New High Score!" badge.
   - Buttons: "Play Again" (restarts immediately) and "Menu" (returns to Start Screen).
4. Update `index.html` and create `css/screens.css`:
   - Modal backdrops, glassmorphism card styling, responsive buttons.

### Task 2: In-Game HUD & Settings Panel
**Type**: HUD & Config  
**Requirements**: UI-03, UI-05  
**Action**:
1. Create `js/ui/SettingsPanel.js`:
   - Configure:
     - Game Mode: dropdown for all 6 modes from `modeManager.getAll()`.
     - Board Size: Small (20x20), Medium (30x30), Large (40x40).
     - Fruits on Screen: 1, 3, 5.
   - Saves preferences to `localStorage` under `snake_settings`.
2. Update HUD in `index.html` and create `css/hud.css`:
   - Score with fruit icon, High Score with trophy icon, Pause button (toggles play/pause icon).
3. Create `css/settings.css`:
   - Floating settings modal with clean toggles and dropdowns.

### Task 3: Mobile Touch Swipe & On-Screen D-Pad
**Type**: Mobile & Controls  
**Requirements**: CTRL-02, CTRL-03, CTRL-04  
**Action**:
1. Update `js/core/InputManager.js`:
   - Add touch swipe handlers on canvas:
     - Record `touchstart` position `{ x, y }`.
     - On `touchend`, compute `dx` and `dy`. If distance > 20px, determine dominant axis and buffer direction.
   - Add touch listeners on D-pad buttons:
     - Support touch and click on buttons with `data-dir="up|down|left|right"`.
   - Prevent default behavior on touch events to prevent browser pull-to-refresh or zoom.
2. Add on-screen D-pad markup in `index.html` inside a `#mobile-controls` wrapper.
3. Create `css/mobile.css`:
   - Shows D-pad on mobile viewports (`@media (max-width: 768px)` or touch devices).
   - Glassmorphism circular D-pad buttons with active press feedback.
