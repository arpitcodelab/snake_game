# Plan 03-01: Game Modes Engine

## Objective
Implement an extensible Strategy-pattern `GameMode` architecture and deliver the 6 core game modes: Classic, No Walls, Two-Headed, Moving Targets, Broken Snake, and Speed Demon, seamlessly integrated into the collision, rendering, and game loops.

---

## Tasks

### Task 1: Base GameMode Strategy & Registry
**Type**: Architecture & Foundation  
**Requirements**: MODE-01, MODE-02, MODE-03  
**Action**:
1. Create `js/modes/GameMode.js`:
   - Base class with extensible hooks:
     - `onWallCollision(head, grid, snake)` -> `{ handled: boolean, collided: boolean }`
     - `onSelfCollision(head, body, snake)` -> `{ handled: boolean, collided: boolean }`
     - `onFoodEaten(food, scoreSystem, snake)`
     - `onUpdate(deltaTime, snake, food, grid)`
     - `getSpeedModifier()` -> default `1.0`
     - `getScoreMultiplier()` -> default `1`
     - `shouldRenderSegment(index, totalLength)` -> default `true`
     - `hasSecondaryHead()` -> default `false`
2. Create `js/modes/ClassicMode.js`:
   - Extends `GameMode` with standard walls kill / self-collision kill rules.
3. Create `js/modes/NoWallsMode.js`:
   - Overrides `onWallCollision`: wraps `head.x` and `head.y` to opposite edges (`c = (c + cols) % cols`).
4. Create `js/modes/ModeManager.js`:
   - Registry mapping mode IDs to mode classes.
   - Provides `getMode(id)` and lists available modes with descriptions.

### Task 2: Advanced Game Modes Implementation
**Type**: Gameplay Mechanics  
**Requirements**: MODE-04, MODE-05, MODE-06, MODE-07  
**Action**:
1. Create `js/modes/MovingTargetsMode.js`:
   - Tracks a 2000ms timer in `onUpdate`.
   - On interval, shifts each non-golden fruit to a random valid adjacent unoccupied tile.
2. Create `js/modes/SpeedDemonMode.js`:
   - `getSpeedModifier()` returns `2.0` (doubles tick rate).
   - `getScoreMultiplier()` returns `2` (doubles points earned).
3. Create `js/modes/BrokenSnakeMode.js`:
   - Overrides `shouldRenderSegment(index, totalLength)`: hides every 2nd or 3rd segment (except head and tail).
4. Create `js/modes/TwoHeadedMode.js`:
   - `hasSecondaryHead()` returns `true`.
   - Validates collisions for both `head` (index 0) and `tail` (last index).

### Task 3: Engine Integration & Verification
**Type**: Integration  
**Requirements**: MODE-01, MODE-02, MODE-03, MODE-04, MODE-05, MODE-06, MODE-07  
**Action**:
1. Update `js/systems/CollisionSystem.js`:
   - Accept active `GameMode` and delegate wall/self checks before falling back to defaults.
2. Update `js/renderer/SnakeRenderer.js`:
   - Check `mode.shouldRenderSegment(i, length)` before rendering body segments.
   - If `mode.hasSecondaryHead()`, render eyes and head styling on the tail segment as well.
3. Update `js/core/Game.js`:
   - Add `setMode(modeId)`.
   - Pass active mode into `CollisionSystem`, `Food`, `ScoreSystem`, and `Renderer`.
   - Apply `mode.getSpeedModifier()` and `mode.getScoreMultiplier()`.

## Verification Plan
1. **Classic Mode**:
   - Drive into wall: verifies game over.
2. **No Walls Mode**:
   - Drive into right wall: verifies snake re-emerges on left side without dying.
   - Drive into top wall: verifies snake re-emerges at bottom.
3. **Moving Targets Mode**:
   - Observe fruits: verify they move every 2s to adjacent tiles without hopping into snake body.
4. **Speed Demon Mode**:
   - Verify tick speed starts at 75ms (2x faster than 150ms).
   - Eat a normal fruit: verify +2 pts awarded instead of +1.
5. **Broken Snake Mode**:
   - Observe snake: verify body has gaps between segments while steering and collisions remain intact.
6. **Two-Headed Mode**:
   - Verify both ends have eyes.
   - Verify driving either end into a wall or body triggers game over.
