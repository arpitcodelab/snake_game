# Plan 02-01: Fruit System & Collision Mechanics

## Objective
Implement fruit spawning and lifecycle management, accurate spritesheet slicing from `apple_types.png`, food collision detection, snake growth, scoring, and dynamic speed acceleration.

---

## Tasks

### Task 1: Fruit Entity & Spawner Lifecycle
**Type**: Entity & Logic  
**Requirements**: FOOD-01, FOOD-02, FOOD-03, FOOD-04  
**Action**:
1. Create `js/entities/Food.js`:
   - Define fruit types with sprite frame indices:
     - `NORMAL`: frame 0 (Apple, 1 pt)
     - `SPECIAL`: frame 6 (Cherry, 3 pts), frame 7 (Strawberry, 3 pts), frame 1 (Banana, 3 pts)
     - `GOLDEN`: frame 13 (Golden Apple, 10 pts, 5000ms duration)
   - Store list of active `items`: each item has `{ x, y, type, points, spriteIndex, isGolden, timer, duration }`.
   - Implement `spawn(snakeBody, grid, count = 1)`:
     - Finds random `{x, y}` within `[0..cols-1, 0..rows-1]` not occupied by `snakeBody` or active fruits.
     - Maintains target count (1, 3, or 5 fruits).
   - Implement `update(deltaTime)`:
     - Decrements golden fruit timer and removes/respawns when expired.
     - Handles periodic golden fruit appearance chance (e.g. 15% chance when standard fruit is eaten).

### Task 2: Food Renderer with Spritesheet Slicing & Glow
**Type**: Rendering  
**Requirements**: FOOD-05  
**Action**:
1. Create `js/renderer/FoodRenderer.js`:
   - Preload `assets/images/fruits/apple_types.png` (1792x128, 14 frames of 128x128).
   - Draw fruit sprite with `drawImage(img, sx, sy, 128, 128, dx, dy, cellWidth, cellHeight)`.
   - Add subtle animation: scale breathing (1.0 to 1.08) using `performance.now()`.
   - Add golden fruit sparkle/glow and countdown warning (flashes when < 1.5s remaining).
   - Fallback rendering with colored glowing circles if the image is still loading.
2. Integrate `FoodRenderer` into `js/renderer/Renderer.js`.

### Task 3: Food Collision, Score System & Speed Progression
**Type**: Collision & Progression  
**Requirements**: CORE-06  
**Action**:
1. Update `js/systems/CollisionSystem.js`:
   - Add `checkFood(head, foodItems)`: returns the food item at `head.x === food.x && head.y === food.y`.
2. Create `js/systems/ScoreSystem.js`:
   - Tracks `currentScore`, `highScore`, `fruitsEaten`.
   - Methods: `add(points)`, `reset()`, `getSpeedMs(baseMs, minMs, stepDown)`.
3. Integrate into `js/core/Game.js`:
   - On tick: check food collision with head.
   - If food eaten:
     - Emit `food:eaten` event via `bus`.
     - Snake grows: `snake.grow(1)`.
     - Score increments and HUD updates.
     - Game speed recalculates: decreases tick interval by 2ms per fruit down to 60ms minimum.
     - Remove eaten food and spawn a replacement.

## Verification Plan
1. **Fruit Spawning Verification**:
   - Verify fruits appear on board and never spawn inside snake segments.
   - Test configurable count: 1, 3, and 5 fruits.
2. **Spritesheet Slicing Verification**:
   - Verify fruits render as sharp sprites (Apple, Cherry, Strawberry, Banana, Golden).
3. **Collision & Growth Verification**:
   - Steer snake to eat a fruit: verify score increases, snake grows by 1, and fruit immediately respawns elsewhere.
4. **Golden Fruit Verification**:
   - Trigger golden fruit: verify 10 pts awarded if eaten, or despawns after 5 seconds if ignored.
5. **Speed Acceleration Verification**:
   - Eat 10+ fruits: verify game tick interval visibly speeds up towards 60ms.
