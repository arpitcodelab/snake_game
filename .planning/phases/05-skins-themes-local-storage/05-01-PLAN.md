# Plan 05-01: Skins, Themes & Local Storage

## Objective
Implement dynamic CSS custom property board themes, 6 unlockable snake skins with milestone progression, arcade-style Top 10 local leaderboard with 3-letter initials, and comprehensive `localStorage` persistence.

---

## Tasks

### Task 1: Board Theme System (CSS Variables & Grid Sync)
**Type**: Theming & Persistence  
**Requirements**: SKIN-01, SKIN-04  
**Action**:
1. Create `css/themes.css`:
   - Define themes via `[data-theme="..."]`:
     - `classic`: Navy/indigo background `#161722`, teal snake `#4ecca3`
     - `dark`: Minimalist AMOLED `#0a0a0e`, emerald `#00ff88`
     - `forest`: Deep jungle `#122014`, vibrant lime `#7bc67e`
     - `space`: Cosmic void `#080816`, nebula purple `#a29bfe`
     - `retro`: Amber CRT scanline `#1a1204`, retro amber `#ffbe76`
     - `ocean`: Deep abyss `#071a2c`, cyan wave `#00d2d3`
2. Create `js/systems/ThemeSystem.js`:
   - `applyTheme(themeId)`: sets `data-theme` attribute and updates `GridRenderer` colors.
   - Saves/loads `snake_selected_theme` from `localStorage`.
3. Add Theme selector dropdown to `SettingsPanel.js`.

### Task 2: Snake Skin System & Milestone Unlocks
**Type**: Customization & Progression  
**Requirements**: SKIN-02, SKIN-03, SKIN-04  
**Action**:
1. Create `js/systems/SkinSystem.js`:
   - Define 6 skins:
     - `classic`: Green palette (Unlocked)
     - `neon`: Cyan & Magenta glow (Unlocked at 25 total fruits)
     - `forest`: Viper green & amber (Unlocked at 50 total fruits)
     - `fire`: Crimson & fiery orange (Unlocked at 100 total fruits)
     - `ice`: Arctic blue & frost (Unlocked at 150 total fruits)
     - `gold`: Shimmering midas gold (Unlocked at 250 total fruits)
   - Track `totalFruitsEaten` in `localStorage`.
   - Methods: `recordFruitEaten()`, `isUnlocked(skinId)`, `selectSkin(skinId)`, `getActiveSkin()`.
2. Update `js/renderer/SnakeRenderer.js`:
   - Apply skin color schemes for head, body, eyes, and glow.
3. Add Skin picker to `SettingsPanel.js` showing lock icons for locked skins.

### Task 3: Local Leaderboard (Top 10 with Initials)
**Type**: Leaderboard & Storage  
**Requirements**: SKIN-04, UI-06  
**Action**:
1. Create `js/systems/LeaderboardSystem.js`:
   - Store top 10 scores per mode in `localStorage` under `snake_leaderboard`.
   - `isTopScore(score, mode)`: checks if score qualifies for top 10.
   - `addScore(initials, score, mode)`: adds entry `{ initials, score, mode, date }`, sorts, caps at 10.
2. Create `js/ui/LeaderboardScreen.js`:
   - Displays ranked list (1st–10th) with rank medals (🥇, 🥈, 🥉), initials, score, and date.
   - Filter tabs for modes.
3. Update `GameOverScreen.js`:
   - When score qualifies for leaderboard, display 3-letter initials input field with a submit button.
4. Update `index.html` with Leaderboard screen and Trophy button in header/menu.

## Verification Plan
1. **Theme Verification**:
   - Switch themes in Settings: verify canvas grid, body background, and UI accents immediately update.
   - Reload page: verify selected theme persists.
2. **Skin System Verification**:
   - Select Classic skin: verify green snake renders.
   - Reach milestone: verify next skin unlocks and can be equipped.
3. **Leaderboard Verification**:
   - Achieve a score: verify 3-letter initials prompt appears on Game Over.
   - Submit initials (e.g. "ACE"): open Leaderboard and verify "ACE" appears in the Top 10 with date and mode.
   - Reload browser: verify leaderboard entries remain intact.
